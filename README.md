# Bridgepoint Lending Desk

Internal CRM for Bridgepoint Lending — a single-page app covering lead intake,
pipeline management, loan processing, commissions, team performance, and a
borrower portal preview.

## Running it

This is a self-contained static page with no build step. Open `index.html`
directly in a browser, or serve the folder with any static file server:

```bash
npx serve .
```

## Demo accounts

All data is in-memory demo data (see the embedded state in `index.html`).
Log in with a username / PIN pair, e.g.:

- `joe` / `1010` — Owner
- `maria` / `2020` — Loan Officer
- `erika` / `3030` — Processor
